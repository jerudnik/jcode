# docs/issues/ — Open issues (DOX)

- Require YAML `status` (`open|in-progress|blocked|partial`), `priority` (`critical|high|medium|low`), `owner` (handle or role), and ISO-date `opened`.
- Optional: `closed`; `related` list of paths, pull requests, or issues.
- Delete solved issues in the same commit; never keep fixed/closed statuses, scratch, or next-action lists.
